Applied Mitigations (Defense-in-Depth):

  1. Indirect Object Referencing: Users request document tokens (e.g. doc_id=doc_01) rather than direct filesystem paths.
  2. Canonical Boundary Enforcement: Absolute path resolution using os.path.realpath() verifies that target files reside strictly inside public_docs.
  3. Filename Sanitization: Stripping directory separators and validating with secure_filename().
  4. Standardized Error Handling: Traversal attempts immediately return HTTP 403 Forbidden without leaking filesystem hierarchy.
