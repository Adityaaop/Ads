1. Introduction & Selected OWASP Category

For this assignment, I selected OWASP Top 10 (2021) Category A01:2021 – Broken Access Control.

Broken Access Control currently holds the #1 position in the OWASP Top 10. Access control mechanisms enforce authorization policies so users cannot access resources or execute actions outside their intended permissions. When access controls are broken, attackers can view unauthorized files, steal server configurations, or access sensitive user records.

In this practical lab, I designed and implemented a dummy web application demonstrating Path Traversal (CWE-22) and Insecure Direct Object Reference (CWE-639) under Improper Access Control (CWE-284). I conducted STRIDE threat modeling, calculated per-threat DREAD scores, implemented Defense-in-Depth mitigations in code, and verified the defenses using 17 automated unit test assertions.

I created an academic portal in Python (Flask) with two setups:

  • vulnerable_app/ (Port 5000): Demonstrates CWE-22, CWE-35 (naive replace bypass), and CWE-639 (IDOR).

# Vulnerable IDOR Endpoint (CWE-639):
@app.route("/api/document/")
def get_document_vulnerable(doc_id):
    # FLAW: No user ownership or authentication check
    doc = DOCUMENTS_DB.get(doc_id)
    return {"status": "success", "doc_id": doc_id, "data": doc}, 200

Failure of Naive Blacklisting (.replace('../', '')):

Developers often attempt to strip ../ with string replacement: filtered = raw.replace("../", ""). Because replacement runs only once, sending ....//confidential/admin_db_credentials.env causes the inner ../ to be stripped, leaving behind ../ and executing traversal successfully with HTTP 200 OK.

7. Mitigation Implementation & Code Comparison

In secure_app/app.py, I implemented a Defense-in-Depth mitigation strategy:

  • Canonical Path Resolution: Using os.path.realpath() and os.path.commonpath() to ensure files remain strictly inside public_docs.
  • Object-Level Authorization (IDOR Prevention): Enforcing ownership check requiring doc['owner'] == current_user or admin.
  • Structured Audit Logging: Function record_audit_log writes JSON events to audit_access.log.
  • DoS Protection: Enforcing os.path.isfile() check and 2MB file size ceiling.

9. Conclusion

This lab demonstrates why Broken Access Control is ranked #1 in the OWASP Top 10. Direct file path concatenation without canonical path checks allows attackers to read sensitive files with simple ../ payloads. Naive string replacement like .replace('../', '') is ineffective against nested sequences like ....//. The best defenses combine canonical path containment validation (os.path.realpath / commonpath) with strict object-level authorization checks.
